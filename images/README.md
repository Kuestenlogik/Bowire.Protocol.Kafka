# images

`icon.png` is the NuGet package icon: Bowire's mark on the light tile, 128 px, so it stays visible on light and dark package pages. It is a copy of `images/icon.png` in [Kuestenlogik/Bowire](https://github.com/Kuestenlogik/Bowire/tree/main/images), which Bowire's branding tool generates. Do not edit it here; when Bowire's logo changes, copy the new file over.
